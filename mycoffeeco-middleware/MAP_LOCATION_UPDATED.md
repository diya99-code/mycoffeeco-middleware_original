## Troubleshooting

### Map shows wrong location?
**Solution**: Update coordinates in Shopify customizer to exact location

### "Get Directions" opens wrong place?
**Solution**: Verify latitude/longitude are correct (no typos)

### Map shows DLF Infinity still?
**Solution**: 
1. Hard refresh browser (Ctrl+Shift+R)
2. Clear Shopify theme cache
3. Re-save the page in customizer

### Map not loading at all?
**Solution**: Check Google Maps API key is correct and Maps Embed API is enabled
