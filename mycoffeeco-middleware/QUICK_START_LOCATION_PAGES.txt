🔄 SUPPORTED URL PATTERNS:

The middleware now supports multiple nesting levels:

/locations
  → /pages/locations

/locations/gurgaon
  → /pages/locations-gurgaon

/locations/gurgaon/dlf-cyber-city
  → /pages/locations-gurgaon-dlf-cyber-city

/locations/gurgaon/dlf-cyber-city/building-14
  → /pages/locations-gurgaon-dlf-cyber-city-building-14

This allows you to create hierarchical location pages:
• Country/City level pages
• Area/Neighborhood level pages  
• Specific building landing pages

🐛 TROUBLESHOOTING:

Redirect not working?
  • Check middleware is deployed and running on Render
  • Verify SHOPIFY_STORE_URL in .env
  • Check Render logs for redirect messages
  • Ensure App Proxy is configured (or use middleware URL directly)

Page shows 404?
  • Verify Shopify page exists
  • Check URL handle: locations-gurgaon-dlf-cyber-city-building-14
  • Ensure page is published (not draft)
  • Check "Hide from search engines" is enabled
